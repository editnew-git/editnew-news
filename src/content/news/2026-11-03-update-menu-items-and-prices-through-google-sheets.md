If your S.A.M. menu is already connected to a designated Google Sheet, update the approved menu values in that sheet. The connected layout uses those values to display the menu.

## Before you start

You need editing access to the source sheet provided at handoff, the correct tab, and a configured layout. Confirm which cells you may edit and which screens use the data. Use only menu information approved for public display.

## Update the menu data

1. **Open the designated sheet.** Use the source-sheet link supplied by your administrator or support team. Confirm that it belongs to the menu you intend to update. If you cannot identify or open it, ask for the correct link and access.

2. **Choose the correct tab and item.** Check the item name and surrounding menu entries before changing a price or description. Some installations use separate tabs or sections for different screens.

3. **Edit only the intended values.** Update the approved item names, descriptions, or prices. Preserve the existing headings, referenced fields, and sheet structure. Ask the layout owner before renaming headings or adding, removing, or moving structural rows or columns.

4. **Confirm the change is saved.** Recheck the edited values in the sheet. Do not add private notes or customer information to a sheet used for public display.

5. **Check the connected layout.** Review the menu in S.A.M. Preview. If you have access to the configured Data Source, compare its received values with the sheet. Follow the refresh guidance supplied for your installation; do not assume that a saved sheet edit has already reached every screen.

6. **Verify every affected display.** Check the new values on the physical screens that use this menu data. Look for incorrect prices, missing text, or text that no longer fits.

## Expected result

The intended menu values appear correctly in the connected layout and on each affected screen.

If the sheet is correct but the display is not, report the sheet tab, item or field, expected value, observed value, and affected screens through your agreed support route or [EditNew Support](https://support.editnew.ca). Do not change sharing permissions or replace connector settings as a routine editing step.
