If content is cut off, stretched, partly covered, or surrounded by black bars, compare the intended layout with the physical screen before changing display settings.

## Before you begin

Have access to the current layout and a fresh photo of the whole affected screen. View the installation safely; ask an on-site contact for the photo if needed.

## Compare the layout and screen

1. **Identify the target.** Record the sign or player ID, the assigned layout, and the screen's location. Confirm that you are reviewing the layout used by that sign.

2. **Check the intended shape.** Note whether the screen and layout are portrait or landscape. Record the display's pixel dimensions if known. Custom displays can use different dimensions from standard TVs; ask support if you are unsure.

3. **Compare Preview with a fresh photo.** Look at the same content in both. Identify which edges are missing, which areas overlap, and where bars appear. Tell support if Preview looks correct but the physical screen does not.

4. **Check the artwork proportions.** Compare the image's width and height with the area where it should appear. Landscape artwork may look stretched or leave unused space in a portrait area. Ask the content creator for a version designed for the intended orientation.

5. **Check whether the bars or overlap belong to the layout.** A black area containing a clock or another element may be intentional. Look for another module, such as time or weather, covering the expected content. Record what you find before changing the layout.

6. **Ask support to check the remaining mismatch.** If artwork and layout appear correct, send the comparison to support so they can verify the applicable player and display settings.

## Expected result

You can show whether the problem is visible in the layout, the source artwork, or only on the physical display. After an authorized correction, check the whole screen again: important content should be visible, artwork should have the intended proportions, and layout areas should appear as intended.

## If the display is still wrong

Send support the sign and layout IDs, screen orientation and known dimensions, the source artwork dimensions, a Preview image, and a fresh full-screen photo. Include recent layout or equipment changes.

If the screen shows coloured signal bars instead of your layout, report that exact symptom rather than treating it as a black border in the design.
