Configure the orientation and resolution of your S.A.M. layout for a landscape or vertical display. You can also upload a custom background image that matches the layout dimensions.

## Before you begin

Open the layout you want to configure from your Layout Dashboard. Have a background image ready if you plan to use one.

## 1. Open Layout Settings

From the Layout Dashboard, open the layout you want to configure, then select the **Settings** gear icon.

![Layout editor with the Settings gear highlighted](https://media.wwds.co/u/59b2fd23-25c3-4f08-bcc1-39297042d754.webp)

## 2. Open Global Settings

In the Settings menu, select **Global Settings**.

![Settings menu with Global Settings highlighted](https://media.wwds.co/u/84df8cc5-0b21-4106-bee8-29f325b1895e.webp)

## 3. Add the width and height fields

Under **Page CSS Properties**, select the **+** button to add two fields:

- `width`
- `height`

![Global Settings dialog with the add Page CSS Properties control highlighted](https://media.wwds.co/u/2a0ede19-6540-4344-8895-ab7452130d1a.webp)

## 4. Set the layout resolution and orientation

Enter the dimensions for your preferred orientation. Include `px` after each value.

- **Landscape:** width `1920px`, height `1080px`
- **Vertical (Portrait):** width `1080px`, height `1920px`

![Global Settings width and height fields set to 1920px and 1080px](https://media.wwds.co/u/77c5e509-0735-4df9-bb29-c871aa972277.webp)

## 5. Set the layout background

To use a custom background, choose a file in the **Background Image** field. For the best visual result, use an image with the same resolution and orientation as the layout.

![Global Settings Background Image upload field highlighted](https://media.wwds.co/u/30fe171e-d8f7-4adb-ae95-23f88d838db0.webp)

## 6. Save your changes

Select **Save** to apply the orientation, resolution, and background settings.

![Global Settings Save button highlighted](https://media.wwds.co/u/c45ac161-a28d-4b32-a033-7e6c21d80836.webp)

## Quick reference

| Orientation | Width | Height |
| --- | ---: | ---: |
| Landscape | 1920px | 1080px |
| Vertical (Portrait) | 1080px | 1920px |

## Expected result

Your S.A.M. layout uses the selected landscape or vertical dimensions, and the uploaded background appears at the configured resolution.
