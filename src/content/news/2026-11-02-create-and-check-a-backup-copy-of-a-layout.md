Create a separate copy and verify it before making a change that may be difficult to reverse.

## When this applies

Use the desktop layout Settings menu with **Copy — Duplicate current layout**. A copy is a separate layout, not an undo operation on the original.

## Before you begin

Open the correct source layout and confirm its ID. Resolve any unsaved work before copying.

## Create the copy

1. Open the Settings gear.
2. Select **Copy — Duplicate current layout**.
3. Enter a clear name that identifies the copy, then select **Save**.
4. Confirm the resulting layout has its own ID.
5. Open that copy and inspect the content you need to preserve.
6. Open the copy's Preview and check its appearance.

## Verify the result

Keep the source and copy IDs distinct. Check important content and settings explicitly; a correct Preview does not prove every schedule, source connection or device assignment was copied.

## When to contact support

Stop if the copy is incomplete or you need to restore content into the original layout. This process does not guarantee restoration of original item IDs, all properties or sign assignments. Do not deploy the backup merely because its Preview looks correct.
