Find the correct **Media** module first, then open its **Add Content** dialog. These are two different steps.

## Before you begin

Open the intended layout and confirm its identity. Preserve any unsaved work before changing screens. These instructions describe the desktop editor with **Preview**, **Remote Control**, and module entries in the right sidebar.

In the left navigation, expand **Layouts** if needed and select the **Layouts** entry beneath it. In **Grid** view, select its linked title; in **Table** view, select its blue numeric ID button. Match both ID and name to the intended layout.

![Left navigation with the Layouts menu expanded and its Layouts entry](https://media.wwds.co/u/pressly-pr-en-20261102-001-2d20330a626d8a23b18b15ac6ff4d9b35f4762925fa82fefdd8dc0d62b8d995e.webp)

## 1. Find Media in the layout editor

1. Look in the right sidebar below **Preview** and **Remote Control**.
2. Find a module entry with the smaller type label **Media**. Its larger display label can be **Set Label** or a custom name.
3. Select that module entry. Wait for the Media content list to appear in the main editor area.

![Media type below Set Label in the right sidebar and the blue Content button in the Media toolbar](https://media.wwds.co/u/pressly-pr-en-20261102-001-e72375dd21ae45d48530e0173142cfb32f88d175d875d25501d98d9be9e477ba.webp)

[Open screenshot at full size](https://media.wwds.co/u/pressly-pr-en-20261102-001-e72375dd21ae45d48530e0173142cfb32f88d175d875d25501d98d9be9e477ba.webp)

The item's wrench menu edits an existing content item. It is not the control for opening the Media module. The layout's Settings gear also has a different purpose.

## 2. Open Add Content

Above the Media content cards, select the blue **Content** button with the plus icon. It opens the **Add Content** dialog.

![Add Content dialog with Upload Image(s) selected and the Your Device button](https://media.wwds.co/u/pressly-pr-en-20260721-001-f702b60b16ff7a72a8164e87f8a85fb5ad6ab1138e8396852a3a14d61a7e8447.webp)

Identify this control by its label and plus icon. Do not look for a plus immediately beside green **SAVE**: the pictured toolbar also has controls such as **Stretch**, **Scale**, and **Advanced** between Content and Save.

For the next steps, use [Upload an image to a S.A.M. layout](https://support.editnew.ca/news/2026-07-21-importing-content-in-runsam-uploading-images-to-a-layout/) or the guide for the content type you want to add.

## If you cannot identify Media

Open the layout's **Settings** gear, then **Module Manager**. Inspect the full list of existing module types and IDs. Close the dialog without making changes after identifying the module.

A custom display label or a camera-shaped icon alone does not establish the module type. Do not add or remove a module merely because its sidebar label is unfamiliar.

## Check the result

The intended Media module is open, and selecting Content opens Add Content. A screenshot of an already-open Add Content dialog does not show where Media is in the surrounding layout editor.

If your sidebar or toolbar differs from the one described, contact [EditNew Support](https://support.editnew.ca) with the layout identity and a cropped screenshot. Hide private account information and unrelated content. Describe whether you are trying to locate Media or the content-add control inside it.
