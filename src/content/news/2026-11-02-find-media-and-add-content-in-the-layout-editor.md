Locate the correct Media module before adding or editing content.

## When this applies

Use this guide in the desktop layout editor with Preview and Remote Control in the right sidebar. An embedded Media editor and a standalone Media form have different toolbars.

## Before you begin

Open the intended layout and confirm its layout ID. Preserve any unsaved work before changing screens.

## Find the module

1. Look below Preview and Remote Control in the right sidebar.
2. Find the entry whose module type reads **Media**. Its larger display label may read **Set Label** or a custom name.
3. Select that entry to open Media.
4. In the embedded editor, find the blue **+** immediately beside the green **SAVE**, above the content cards. This opens Add Content.

## If Media is unclear

Open the Settings gear, then **Module Manager**. Read the existing module types and IDs. Close the dialog without changes when finished. Adding or removing a module is unnecessary just to identify it.

## Check the result

You should be viewing the intended Media module and its content controls. The Add Content dialog is a later screen; it does not identify which module you opened.

## When to contact support

If your sidebar or toolbar differs, stop before changing the layout. Send support the layout ID and a screenshot with account details concealed. Do not identify a module from an icon alone.
