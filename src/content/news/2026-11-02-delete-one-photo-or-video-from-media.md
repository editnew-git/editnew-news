Remove an individual photo or video only after identifying it and preserving anything you may need later.

## Before you begin

Confirm the layout ID and the intended Media item. Keep the original file and record its order, duration and schedule. If you need a backup, create and check a separate layout copy first. A copy is not an undo operation on the original layout.

These steps apply to the Media item menu with **Delete** and a red **Are you sure?** confirmation. Removing an entire module uses a different process.

## Delete the item

1. Open the correct layout and its Media module.
2. Identify the photo or video by its content. Open that item's wrench menu and select **Delete**.
3. Review the red confirmation. Cancel if the item is not the intended target.
4. Confirm only when you intend to remove that item. In this interface, that confirmation commits the deletion without a separate main SAVE. Leaving the editor without saving does not undo it.
5. Reopen Media and confirm that the item is gone and the expected remaining items are present.
6. Reload Preview and observe the remaining playlist. Check a physical display separately when applicable.

## If you need the item again

A retained original file can be uploaded as a new item. Check its order, duration and schedule separately; do not assume the original item identity or settings return automatically. Contact support before deletion if you need a guaranteed restoration path.
