Convert an existing layout into a reusable template that other users can find and use.

## Before you begin

Make sure you have:

- access to **Admin Tools** in S.A.M.;
- the layout you want to convert; and
- a clear screenshot of the layout preview to use as the template thumbnail.

## 1. Take a screenshot of the layout preview

Open the layout preview and take a clear screenshot. You will upload this image as the template thumbnail in Step 9.

![Layout preview showing an analog clock on a dark background](https://media.wwds.co/u/pressly-pr-en-20260929-001-0eec459bba9388d7338fed896eb0506ad9f1d9a25021775fa87f38ab01cf8044.webp)

## 2. Go to Admin Tools

From the main menu, select **Admin Tools**.

![S.A.M. layout editor with Admin Tools highlighted in the main menu](https://media.wwds.co/u/pressly-pr-en-20260929-001-6fb407dabd0834128659288fc0afd729275fb27de93d556765c2ea1ec7d4b7a9.webp)

## 3. Open Templates

Under **Admin Tools**, select **Templates**.

![S.A.M. Admin page with Templates highlighted under System Setup](https://media.wwds.co/u/pressly-pr-en-20260929-001-3275742bb6ffef330648b48e417126aeafd34e53b6c2b162eab45f946ed17ec7.webp)

## 4. Select Import

On the Templates page, select **Import** to create a template from an existing layout.

![Templates page with the Import button highlighted](https://media.wwds.co/u/pressly-pr-en-20260929-001-1b00d53b2ef102771976c96ce00b519d139385d197c67d9d5291c7107d9c1d2c.webp)

## 5. Select the layout

Use the layout list in the **Template Import** window to select the layout you want to convert.

![Template Import dialog with the layout selector at the top](https://media.wwds.co/u/pressly-pr-en-20260929-001-3083b8e82bc24b4dbb1058a278bf5fe474ec1336a041dc5404cae7cd126ed07f.webp)

## 6. Add the template label and description

Enter a clear **Label** and a short **Description** that explains what the template is used for.

![Template Import dialog with Label and Description fields highlighted](https://media.wwds.co/u/pressly-pr-en-20260929-001-1bc2ea1aa92ed8f3ced93b82bccd7744ebf7a3d2db1cc8e7c96e2d23a47d134e.webp)

## 7. Select a category

Choose the category that best describes the layout's purpose or format.

![Template Import dialog with the Category menu expanded](https://media.wwds.co/u/pressly-pr-en-20260929-001-39d276e83770c3abf8bf0fb43e7e441acca55aaa42e048c01ec444053bef3a72.webp)

## 8. Add tags

Add relevant tags to make the template easier to find. Separate each tag with a comma.

For example: `Media, HTML, Weather`

![Template Import dialog with the Tags field highlighted](https://media.wwds.co/u/pressly-pr-en-20260929-001-367efab8a2598b3341449992c1e35806f8647f25dac3f772b90e8930bcaa7b85.webp)

## 9. Upload the template thumbnail

Select **Choose File**, then upload the layout-preview screenshot you created in Step 1. This image will be used as the template thumbnail.

![Template Import dialog highlighting the Choose File control for uploading a thumbnail](https://media.wwds.co/u/pressly-pr-en-20260929-001-4eb8332d57ed848f00650ab47ee457b8427c50128b63f181d455cb6ef66540a7.webp)

## 10. Save the template

Review the label, description, category, tags, and thumbnail. When everything is correct, select **Save**.

## Expected result

The layout is now available as a reusable template.
