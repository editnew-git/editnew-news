A reusable template can affect what other editors create. Prepare and review the source layout before an authorized administrator imports it into a template catalog.

## Prepare the source

1. Confirm the source layout's name and ID, ownership and permission to reuse its content.
2. Make a separate reviewed copy if changes are needed. Identify its modules, remove sample or private content as appropriate, and verify the layout's Preview.
3. Prepare a clear screenshot of that Preview for the proposed thumbnail. Check that it contains no private data, account details or controller links.
4. Write a proposed label, description, category and search tags. Explain the intended display shape and content purpose.
5. Identify any dependencies that a new copy would require, such as data sources, fonts, media assets or account-specific modules.

## Have the administrator verify the import

Template administration is account-specific. If an authorized administrator has **Admin Tools → Templates → Import**, have them inspect the actual source selector, metadata fields, thumbnail control and publication scope before committing. If those controls are absent, stop and request the correct administrator; do not substitute ordinary layout copying for catalog publication.

Availability, tag-entry format and catalog visibility depend on the administration form. Confirm them before committing; do not assume Save automatically makes the template available to other users.

After an approved import, verify the resulting template's identity and visibility in the intended catalog. Create a separate test instance and check its modules, assets and Preview before describing the template as ready for reuse.
