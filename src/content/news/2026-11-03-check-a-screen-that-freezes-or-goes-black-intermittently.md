If a screen freezes or goes black from time to time, record the failure while it is happening. A player may still appear online even when the TV is not showing the expected picture.

## Before you begin

Have an on-site person who can safely see the screen. Any refresh or restart must use the instructions and access approved for that player. If the equipment is inaccessible or there is an electrical concern, ask the responsible local team for help.

## Check the failure

1. **Record the pattern.** Note the sign or player ID, location, time, and how often the problem occurs. Say whether the screen is frozen on one image, completely black, or showing a message.

2. **Check the visible display.** Confirm that the TV is using the input connected to the player. Take a fresh photo and note which content was playing when the problem began.

3. **Check connection status separately.** If you can see the player's status, record whether it appears online. Otherwise, ask support to check. Include any recent power, network, content, or equipment changes.

4. **Ask support which action to use.** Support may direct a page refresh, an application restart, a device restart, or a power cycle. These are different actions. Use only the control or procedure confirmed for your player, and record which action you performed.

5. **Verify playback afterward.** Watch the physical screen and confirm that playback matches the intended content. For rotating content, wait for the expected transition. Note how long recovery lasts and whether the same failure returns.

## Expected result

The screen resumes normal playback, or you have a clear record of the failure for support. Temporary recovery is useful evidence, but it does not confirm that the underlying problem has been fixed.

## If the problem returns

Send support the player ID, failure times, screen photos, connection status, and the exact recovery action already tried. Mention whether the failure affects the same content or happens at a recurring time.

If a supplied control is missing or does not behave as described, report that result to support before trying another action.
