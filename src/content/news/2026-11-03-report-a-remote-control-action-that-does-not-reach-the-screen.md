A Remote Control button may respond in your browser while the intended screen stays unchanged. Use these checks to show support where the response stops.

## Before you begin

You need authorized access to the control and a current view of the physical screen, either in person or through someone at the site. Use only an approved, non-emergency test action in a test environment. Follow your organization's established procedure for emergency systems.

## Check the target and record the response

1. Identify the screen, sign and layout you intend to control. Record whether ordinary content is still playing.
2. Check that you opened the control intended for that layout. If you use a saved link or QR code, note whether the layout has changed since that link was supplied. Ask support to verify an uncertain link.
3. For an approved non-emergency test, record the action name and the time, including your time zone. Try it once and note any confirmation or error in the control interface.
4. Compare that response with the layout Preview, if available, and the physical screen. Describe each separately: for example, the button changed state but the screen continued its normal playlist.
5. Report whether the issue affects one action, one screen or several screens. Mention any other controls you have already observed working; a working navigation button does not establish that every control works.

## Expected result

The approved action produces the intended change on the correct screen. A confirmation in the browser alone does not confirm the screen received it.

## If the screen does not respond

Stop repeated tests and send your findings through your agreed support channel. Include the target screen and layout, action and time, normal playback status, interface response, physical result and a screenshot or photo that contains no sensitive information. Tell support if the failure started after a layout change.

Support can investigate the control, layout and player connection from that evidence. If this specifically affects a copied layout's presentation control, use [Report a copied layout whose presentation control fails](https://support.editnew.ca/news/2026-11-02-report-a-copied-layout-whose-presentation-control-fails/).
