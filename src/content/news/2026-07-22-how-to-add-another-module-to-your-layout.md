Add a module only after confirming that the intended layout does not already contain the type you need.

## Before you begin

Open the intended layout and confirm its identity and your editing permission. Check which screens use the layout before changing it.

A module's display label may be a custom name or **Set Label**. An unfamiliar label does not mean the module is missing. Use [Choose a module for common layout content](https://support.editnew.ca/news/2026-11-02-choose-a-module-for-common-layout-content/) if you are unsure which type performs the task.

## Add the module

1. Select the layout's **Settings** gear, then **Module Manager**.
2. Inspect the complete list of existing module types and IDs. If the required module is already present, close the manager without changes and open that module.

![Add/Remove Modules dialog with Select type selector, ADD MODULE button, and existing module type and ID tiles](https://media.wwds.co/u/pressly-pr-en-20260722-001-26e9eb3dd69c0132fdfc6ea5d00324daaeb1f9420f4b71c486b663ae02e91e3b.webp)

[Open screenshot at full size](https://media.wwds.co/u/pressly-pr-en-20260722-001-26e9eb3dd69c0132fdfc6ea5d00324daaeb1f9420f4b71c486b663ae02e91e3b.webp)

This screenshot shows an existing layout's module inventory. The add-and-save examples below use a separate demonstration layout that starts with Media only.

The **Select type...** dropdown and **ADD MODULE** button are above the existing module tiles. The tiles show the layout's current modules and their IDs. Do not click a tile to choose a new module type: selecting an existing tile exposes that module’s removal controls.

3. If you need another module, choose its type in **Select type...**. This selector is separate from the tiles for modules already in the layout.
4. Select **Add Module**. A provisional new module tile and the manager's **Save** button appear. Save is not shown in the initial unchanged manager view.

![Add/Remove Modules with a provisional unsaved new module tile and the green Save button](https://media.wwds.co/u/pressly-pr-en-20260722-001-f3d57a5cbc6f5ad60e8720781e2c1973ec5a8c2a14313e0bb18ade442b0a6b75.webp)

[Open screenshot at full size](https://media.wwds.co/u/pressly-pr-en-20260722-001-f3d57a5cbc6f5ad60e8720781e2c1973ec5a8c2a14313e0bb18ade442b0a6b75.webp)

The new tile in this screenshot is unsaved. Its provisional type label and ID are not the final saved identity.

5. Select the manager's **Save** to commit the addition. After the editor reloads, reopen **Module Manager**.

![Reopened Add/Remove Modules showing the saved Text Block type and its final module ID beside Media](https://media.wwds.co/u/pressly-pr-en-20260722-001-3e51695ac653ff76e0e2544c0371fde56e2aa0d87c2244cae1963bc4a544c78f.webp)

[Open screenshot at full size](https://media.wwds.co/u/pressly-pr-en-20260722-001-3e51695ac653ff76e0e2544c0371fde56e2aa0d87c2244cae1963bc4a544c78f.webp)

The reopened manager shows the saved **Text Block** type in this example.

6. Confirm that the intended type was added once, then record its saved module ID and display label. The temporary tile shown before Save can use a different ID or type label; identify the saved module after reopening.

## Configure and verify it

Open the new module from the layout's module list. Inspect its existing content and settings; do not assume a newly added module is empty. Follow that module's configuration guide to check its content, data connection, appearance, and schedule.

After completing and saving its configuration, reload the layout's own **Preview** and check the expected result. Verify the physical display separately if the layout is assigned to a screen.

## If the result is unclear

If the type selector, Add Module, or Save control differs from these instructions, stop and contact [EditNew Support](https://support.editnew.ca). Provide the layout identity, intended module type, and a screenshot with account details concealed. Do not add the same module repeatedly while waiting for the editor to update.
