Add an image through the intended Media module, then verify the saved item and its appearance in Preview.

## Before you begin

Have an image approved for display and permission to edit the intended layout. Confirm the layout identity and which screens use it.

Open its **Media** module before looking for the upload controls. If you need help finding it, follow [Find Media and Add Content in the layout editor](https://support.editnew.ca/news/2026-11-02-find-media-and-add-content-in-the-layout-editor/).

## 1. Open Add Content

In Media, select the blue **Content** button with the plus icon to open **Add Content**.

![Media type below Set Label in the right sidebar and the blue Content button in the Media toolbar](https://media.wwds.co/u/pressly-pr-en-20261102-001-e72375dd21ae45d48530e0173142cfb32f88d175d875d25501d98d9be9e477ba.webp)

[Open screenshot at full size](https://media.wwds.co/u/pressly-pr-en-20261102-001-e72375dd21ae45d48530e0173142cfb32f88d175d875d25501d98d9be9e477ba.webp)

## 2. Choose an image from your device

In the dialog's **Content Type** selector, choose **Upload Image(s)**. Select **Your Device** to open your computer's file picker. Choose the image there and return to the upload dialog.

![Add Content dialog with Upload Image(s) selected and the Your Device button](https://media.wwds.co/u/pressly-pr-en-20260721-001-f702b60b16ff7a72a8164e87f8a85fb5ad6ab1138e8396852a3a14d61a7e8447.webp)

The screenshot shows the Add Content dialog. Your computer's file picker opens after you select Your Device.

## 3. Save the upload

Review the selected file, then select the green **Save** in the upload dialog.

![Add Content dialog with the green Save button available after selecting an image](https://media.wwds.co/u/pressly-pr-en-20260721-001-645d5a088c55115cd105b61097ab10ec766652fc8f1f3efa540c229f79e8add0.webp)

This Save belongs to the upload. In this form, it saved the image without a second click on the Media toolbar's main **SAVE**. Selecting a file alone does not finish the upload.

Allow processing to finish. **Finishing up** is an intermediate message, not confirmation that the item is ready.

## 4. Reopen Media and check the saved item

Reopen Media and confirm the new image is present. Check its position, duration, and schedule rather than assuming where it was inserted.

![Uploaded support-guide-sample image present in the reopened Media list](https://media.wwds.co/u/pressly-pr-en-20260721-001-6b69e1e76f08d512104a9de440b6eb9bde094a2bed829706102805533aa428ce.webp)

[Open screenshot at full size](https://media.wwds.co/u/pressly-pr-en-20260721-001-6b69e1e76f08d512104a9de440b6eb9bde094a2bed829706102805533aa428ce.webp)

The sample image above was still present after reopening Media. This confirms that the upload was saved; Preview and the physical screen require their own checks.

These steps apply to the form with **Upload Image(s)** and **Your Device**. If the expected controls are absent, ask support for the matching workflow instead of selecting a different content type by guesswork.

## Verify the result

Open the layout's own **Preview** and reload it after saving. Wait for the image's place in the playlist and check the actual picture, not just its thumbnail. Check the assigned physical display separately before considering a live update complete.

## If the upload does not finish

Reopen Media before retrying, in case the image was already saved. Record the exact error, file type, file size, and image dimensions. Do not rename a file extension to force it through the picker.

Uploading an image does not require deleting an existing item. If you also intend to remove a placeholder, identify that item separately and preserve anything you need before confirming deletion.

Contact [EditNew Support](https://support.editnew.ca) if processing does not finish, the saved image is absent, or it does not appear in a fresh Preview. Ask about the file and account limits that apply to your installation; one successful upload does not establish a maximum file size.
