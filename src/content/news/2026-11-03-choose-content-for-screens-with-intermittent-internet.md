For a screen that connects to the internet only at certain times, choose content that suits those connection windows. Downloaded media and live web content have different requirements, so confirm the plan with support for the actual player.

## Before you begin

Identify the affected player, its normal connection pattern, and the content you want to show. Ask support which content types are supported while that player is offline.

## Plan and check the content

1. **Describe the connection pattern.** Note when the screen usually connects and how long those opportunities last. Agree with support which offline periods are expected for this installation and which should be reported.

2. **Separate downloaded media from live content.** List uploaded images and videos separately from websites, streaming video, and live feeds. A live page may need internet when it is displayed; do not assume it will behave like a downloaded image.

3. **Choose a suitable starting set.** Work with support to use supported images or video files where appropriate. Keep the planned update manageable for the available connection time. Ask the content owner for suitable files if a live page is not appropriate.

4. **Prepare changes before moving live screens.** Review the intended content and layout first. Coordinate changes to screen assignments with support when connection opportunities are limited.

5. **Confirm synchronization.** Allow the player to download the required update while it is connected. Have support confirm completion rather than judging readiness from a brief online appearance.

6. **Check real playback.** With support, test the intended content under the site's normal connection conditions. Check the physical screen during an offline period and after it reconnects. Record missing content, errors, or updates that did not arrive.

## Expected result

You have a content plan that has been checked on the actual player under the expected network conditions. The screen shows the agreed content, and new updates arrive when synchronization completes.

## If content fails or stays out of date

Tell support which player and content item were affected, when the connection was available, and what the physical screen showed. Include a fresh photo and the last update you expected to see.

Support can review the content choice, download completion, and connection pattern before the next change.
