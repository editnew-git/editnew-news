This guide explains how to display a specific item from a connected Google Sheet using a **TextBlock** module in S.A.M.

## What you’ll accomplish

You’ll add a TextBlock module to your layout, connect it to a specific Google Sheet field, and display that field’s value.

## Before you begin

- Open the S.A.M. layout you want to edit.
- Confirm that the layout already has a working Google Sheets connector.
- Make sure the required item is available in the connected sheet.

## Instructions

### 1. Open Module Manager

From your layout, select the **Gear** icon to open the layout settings, then select **Module Manager**.

![S.A.M. layout settings with Module Manager highlighted](https://media.wwds.co/u/12581e3e-1e2c-4bd9-b1a5-e720717985fe.webp)

### 2. Open the module-type menu

In the **Add/Remove Modules** window, open the **Select type** menu.

![Add or Remove Modules window with the module type selector highlighted](https://media.wwds.co/u/20fe3027-1feb-4775-b481-71e031ddeb8e.webp)

### 3. Select Text Block

Choose **Text Block** from the list of available module types.

![Module type menu with Text Block highlighted](https://media.wwds.co/u/2e2eb90f-596c-45a9-80a5-30f7504a04e8.webp)

### 4. Add the module

Select **Add Module**. The new TextBlock module appears in the module list.

![Add or Remove Modules window with Add Module highlighted](https://media.wwds.co/u/101f43d7-986b-4395-ae5f-3a88a323cfed.webp)

### 5. Save the module configuration

Select **Save** to confirm the new module.

![Add or Remove Modules window with Save highlighted](https://media.wwds.co/u/6e37895c-498b-48e1-9d39-bd6d83ce078d.webp)

### 6. Open the Text Block module

Return to the layout and select the newly added **Text Block** module from the sidebar.

![S.A.M. layout sidebar with the Text Block module highlighted](https://media.wwds.co/u/5fc5a978-b90f-40eb-b252-6209a0a0d056.webp)

### 7. Open the Google Sheets field selector

In the Text Block settings, open the **GS Connector** field selector to view data from the connected Google Sheet.

![Text Block settings with the GS Connector field selector highlighted](https://media.wwds.co/u/21bfef81-f26d-4625-a957-56c6b7804b82.webp)

### 8. Select the item

Choose the specific Google Sheet item you want the TextBlock to display.

![GS Connector field list with a specific Google Sheet item selected](https://media.wwds.co/u/038245b8-9932-41fd-b426-a15e12e34964.webp)

### 9. Insert the field

Select **Insert Field** to add the chosen item to the TextBlock editor.

![TextBlock settings with the Insert Field button highlighted after a Google Sheet item is selected](https://media.wwds.co/u/86a60aff-c553-44f8-9236-0ae0e18dd8ef.webp)

### 10. Save your changes

Select **Save** to confirm the TextBlock settings.

![S.A.M. TextBlock settings with the Save button highlighted](https://media.wwds.co/u/3ba34bd4-ee95-4bda-9cda-b72691953294.webp)

## Expected result

The selected Google Sheet item is now referenced in the TextBlock and displayed in your S.A.M. layout. When the connected sheet value changes, the TextBlock can use the updated value from the connector.
