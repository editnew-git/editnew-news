Use a **Text/HTML item in Media** for a message that rotates with other content. Use **Text Block** for a fixed text region.

## Open the right editor

Confirm the layout ID and Media module. Its sidebar label may be customized; **gear tab → Module Manager** shows module types and IDs. Return with the **house tab**.

- For a new announcement, open Media and select its blue **Content** button. In **Add Content**, choose **Text/HTML**, then open the offered text editor.
- For an existing announcement, find that item and use its **wrench menu → Edit Text**. Do not add a second copy of the message.

## Save and read back

1. Enter the message and apply readable formatting.
2. If you use **Source code**, select its **Save** to accept the HTML into the editor draft.
3. Select the main green **SAVE** at the top of the Media editor.
4. When the Media list returns, reopen the same item and confirm the saved words.
5. Inspect its order, duration and schedule separately. Use each settings form's own Save and reopen it to verify the values; do not assume one generic final save handles every form.

![Media Text/HTML editor showing the main green SAVE after accepting a source edit](https://media.wwds.co/u/pressly-pr-en-20261102-003-705a31302a713cf6562149ddef528a05ed59c5e1cff101ed8432fca2d3b94108.webp)

[Open the Media text-editor screenshot at full size](https://media.wwds.co/u/pressly-pr-en-20261102-003-705a31302a713cf6562149ddef528a05ed59c5e1cff101ed8432fca2d3b94108.webp).

Open the layout's own **Preview** from the house tab, reload it and observe the announcement's turn. Check wording, contrast, position and sequence. A saved announcement does not itself establish playback on the physical display.

If the saved item, fresh Preview and physical screen disagree, contact [EditNew Support](https://support.editnew.ca) at [info@editnew.ca](mailto:info@editnew.ca). Include the layout/item identity, Save time with timezone and the result at each checkpoint.
