Use a **Text/HTML** item in Media when a message should rotate with other content. For a message in a fixed region, use [Save a fixed Text Block message](https://support.editnew.ca/news/2026-11-02-save-a-fixed-text-block-message/).

## Before you begin

Open the intended layout and Media module. Have your approved message ready and confirm which screens use the layout. If the announcement already exists, identify it by its text and edit that item.

## Open a new or existing announcement

1. To create a new announcement, select **Add Content** using the matching **+** or Content control, then choose **Text/HTML**.
2. To update an existing announcement, open that item's wrench menu and choose **Edit Text**.
3. Enter or revise the message and apply readable formatting.

## Save and check the playlist

1. If you use **Source code**, select **Save** in that dialog to return to the text editor.
2. Select the main green **SAVE** in the Media editor. Saving the source dialog alone does not commit the announcement.
3. Wait for the Media list to return. Reopen the same item and confirm the saved words and formatting.
4. Check its playlist position, duration and schedule. Complete the playlist or layout Save after changing those settings.

## Verify the result

Open and reload the layout's own **Preview**, then wait for the announcement's turn. The text editor's toolbar Preview is a separate control. Check the message, contrast, formatting and order, then check an assigned physical display.

**Expected result:** the intended announcement is saved once, appears in the right place in the playlist and plays correctly on the screen.

## If the result is wrong

If the reopened item still has old text, check the layout and item identity and finish the main SAVE. If the saved item is correct but Preview is old, reload Preview and observe the playlist before making another change.

If the text does not persist, a fresh Preview remains wrong or the physical display differs, contact [EditNew Support](https://support.editnew.ca). Include the layout ID, time of Save with time zone, expected message and what you observed.
