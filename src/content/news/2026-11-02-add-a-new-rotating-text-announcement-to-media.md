Add a new Text/HTML item when a message should rotate with other Media content. Use Text Block instead when the message belongs in a fixed text region.

## Before you begin

Open the intended layout and confirm the Media module. Have the message ready. If you only need to change an existing announcement, edit that item instead of creating a duplicate.

## Add the announcement

1. Open Media and select **Add Content** using the matching **+** or Content control.
2. Choose **Text/HTML** and open its editor.
3. Enter the message and apply readable formatting.
4. If you use **Source code**, select **Save** in that dialog to return the edit to the text editor.
5. Select the main green **SAVE** in the Media editor. The source-dialog Save alone does not commit the announcement.
6. Wait for the Media list, then identify and reopen the new item. Confirm its actual saved text.
7. Check its position, duration and schedule rather than assuming where it was inserted.

## Verify the result

Reload the layout's own Preview and wait for the announcement's turn. Check the words, formatting and contrast against the background. Check an assigned physical display separately.

If the new item is missing or has old text, confirm the layout and Save stages before adding another item. Contact support with the layout ID, expected text and observed result if the saved item or fresh Preview remains wrong.
