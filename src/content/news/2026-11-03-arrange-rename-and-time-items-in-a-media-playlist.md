Organize a S.A.M. media playlist so its items are easy to identify and appear in the intended order. For still images that offer a Duration control, you can also adjust how long each image is shown.

## Before you start

You need editing access to the intended layout and media area. Confirm which screens use that layout before changing it; more than one screen may share the same content.

## Edit the playlist

1. **Open the active layout.** In **Layouts**, select the layout assigned to the intended screen. Open the media area you want to change. Its name depends on the layout design.

2. **Give items useful labels.** Open an item's **Config** or settings control and edit its label where available. Use a name that helps your team recognize the content, then save. Changing an item label does not rewrite words embedded in an image.

3. **Arrange the items.** Where the media list supports dragging, move each item into the intended position. Save the revised playlist order.

4. **Check still-image duration.** Open the image item's settings or scheduling controls. If a **Duration** field in seconds is available, enter the intended display time and save. Duration is separate from the dates or times when an item is eligible to play. If the control is missing, ask support how timing is handled for that item.

5. **Review the complete sequence.** Open Preview and watch the playlist through a full cycle. Check the order, image readability, and display time. Check any existing schedule if an expected item is missing.

6. **Verify the assigned screen.** Confirm the result on the physical display after it receives the update. If the screen differs from Preview, record which item differs and what you observed.

## Expected result

The playlist has recognizable labels, the intended order, and verified timing for the still images you changed.

Video and other media types may handle playback timing differently. If their behavior is unclear, provide support with the media type, item name, current settings, and observed result through your agreed route or [EditNew Support](https://support.editnew.ca).
