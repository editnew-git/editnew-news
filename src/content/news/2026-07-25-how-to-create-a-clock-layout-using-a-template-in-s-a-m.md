Create a new clock layout in [RunSam.com](https://runsam.com) using the **Clock with Logo Integration** template, then replace the default logo with your own.

## Before you begin

You will need:

- Access to your S.A.M. account
- A logo file saved on your computer
- For best display quality, a 650 × 650 pixel PNG logo with a transparent background

## Create the clock layout

1. Go to RunSam.com and sign in to your S.A.M. account.

   ![S.A.M. sign-in page](https://media.wwds.co/u/afe96cf6-e2a6-47b9-918a-89c3c47b671e.webp)

2. From the main menu, select **Layouts**.

   ![Layouts option in the S.A.M. main menu](https://media.wwds.co/u/2048dd7c-ba8c-471c-b6b6-8b1884c36280.webp)

3. Select **New Layout**.

   ![New Layout button on the S.A.M. Layouts page](https://media.wwds.co/u/462e10f7-71cf-4e74-a247-6da201be7750.webp)

4. Find and select the **Clock with Logo Integration** template.

   ![Clock with Logo Integration template in S.A.M.](https://media.wwds.co/u/aa97c6fc-6589-473e-93f0-164068442353.webp)

5. Enter a name for your layout, then select **Save**.

   ![Layout name field and Save button in S.A.M.](https://media.wwds.co/u/a1caf612-efde-46df-be41-bc1d6e18863c.webp)

## Replace the default logo

6. Select **Add Your Logo** to open the logo settings.

   ![Add Your Logo control in the clock layout editor](https://media.wwds.co/u/6416ad0f-c828-4f07-b825-b1e2118f128c.webp)

7. Select the **gear** icon on the existing logo, then delete the logo.

   ![Gear icon for the existing logo in the clock layout editor](https://media.wwds.co/u/f592477c-7ef2-4b00-b213-66844fd468b7.webp)

8. Select **Content** to open the content library.

   ![Content option for adding a logo in S.A.M.](https://media.wwds.co/u/86557316-810b-4052-bb02-2cc160dfedc0.webp)

9. Select **Your Device**.

   ![Your Device upload source in the S.A.M. content library](https://media.wwds.co/u/8d2b1fe1-866c-4f39-85d6-16f5d50fd498.webp)

10. Choose your logo file from your computer and upload it.

    ![Logo file selected for upload in S.A.M.](https://media.wwds.co/u/a4269847-a987-485a-9fc2-815e05a38fc5.webp)

11. Select **Save** to apply your changes.

    ![Save button for applying logo changes in S.A.M.](https://media.wwds.co/u/d577403e-0202-43dc-972c-5411a8e344a3.webp)

## Expected result

Your new clock layout is saved with your uploaded logo in place of the template logo.
