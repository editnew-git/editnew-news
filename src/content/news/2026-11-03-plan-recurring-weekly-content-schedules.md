A weekly content plan describes what should play on each screen on particular weekdays and at particular times. Prepare that plan before configuring a recurring schedule so the person setting it up can verify the intended result.

## Before you begin

Identify the screens and layouts involved, the content for each period, and the people authorized to manage them. Confirm the time zone used by the recurring scheduling feature for each target screen.

A one-time media start/end window and a recurring weekly rule serve different purposes. Do not assume they use the same time basis or combine in the same way.

## Prepare the weekly plan

1. **List the target screens.** Record which player serves each physical screen and which layout it should use. Note any locations in different time zones.
2. **Describe each recurring period.** Write down the weekdays, start time, end time, and content expected during that period. Make the intended local time explicit.
3. **Separate one-time notices.** Identify content that should appear only between particular calendar dates. Ask the account administrator or support how those date limits interact with the recurring schedule before combining them.
4. **Resolve gaps and overlaps.** State what should play outside the planned periods and flag any periods that overlap or cross midnight. Have the person configuring the schedule confirm the supported behaviour.
5. **Confirm timezone handling.** Verify the target device's configured time zone and the time basis used by the recurring scheduler. Ask how daylight-saving changes affect the planned times when relevant.
6. **Test the result on the intended sign.** Arrange an approved test before relying on the schedule. Observe the screen before, during, and after a planned period, and check both a day when it should run and a day when it should not.
7. **Keep the plan with the results.** Record the screens tested, expected periods, actual observations, and any remaining differences for the person maintaining the schedule.

## Expected result

You have a clear weekly plan and confirmed expectations for each screen. The configured schedule has been checked against that plan on the physical display.

## When to ask for help

Contact [EditNew Support](https://support.editnew.ca) if the recurring scheduling feature is unavailable, its time zone is unclear, or overlapping rules, overnight periods, or date-limited notices produce unexpected results.

Provide the target player and layout identifiers, intended weekdays and times, applicable time zone, and what the screen actually showed.
